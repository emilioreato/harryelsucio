# Imágenes de muestra

La aplicación descubre una escena cuando su carpeta contiene exactamente una imagen `True_color` y una `SWIR` de la misma adquisición. Se admiten JPG, PNG y TIFF. Que dos composiciones tengan el mismo tamaño no demuestra que estén georreferenciadas o alineadas.

Las cinco escenas adicionales se identifican como `test1` a `test5` en el selector, después de los tres casos originales. Cada carpeta conserva sus imágenes, referencia `Wildfires` y `metadatos.json` con procedencia y datos de adquisición. `Wildfires` es una composición visual aproximada: no es una etiqueta validada, verdad terreno ni medición de temperatura, y no se usa para clasificar la superficie.

Las parejas de La Mierla, Madrid–Ávila y Niebla se conservan aquí como fuente única; las copias idénticas de `DOCUMENTACION/Presentacion reto/` se quitaron. Esa carpeta mantiene los enunciados y las referencias disponibles.
