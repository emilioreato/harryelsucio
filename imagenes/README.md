# Imágenes precargadas

Cada subcarpeta representa una escena y debe incluir exactamente una imagen cuyo nombre contenga `True_color` y otra cuyo nombre contenga `SWIR`. Las dos deben corresponder a la misma adquisición. Se admiten JPG, PNG y TIFF; la aplicación descubre automáticamente las carpetas que cumplen esta estructura.

Las parejas incluidas aquí se copiaron sin modificar desde `DOCUMENTACION/Presentacion reto/`. Se conserva esa carpeta original. Los archivos `Wildfires` no se usan como imagen de entrada para la segmentación.
